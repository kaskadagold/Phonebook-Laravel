# Телефонный справочник
Веб-приложение "Телефонный справочник" позволяет пользователям добавлять, просматривать, редактировать и удалять контакты. Написано на PHP с использованием фреймворка Laravel.

## Описание
Данное приложение позволяет создавать, редактировать, удалять и просматривать контакты с привязкой к пользователю. Реализована возможность поиска по списку контактов (по имени и телефону), а также их сортировка по алфавиту и уровню приоритета (высокий/средний/низкий). Кроме того, к контактам можно подгружать изображения.

Если введенные данные не позволяют создать/обновить контакт таким образом, чтобы он был уникальным, то программа предупредит о существовании такого контакта (через flash-сообщения) и не создаст дублирующую запись. Также предусмотрена защита от редактирования/удаления контактов, привязанных к другому пользователю.

Реализовано кэширование данных при получении полного списка и просмотра детальной страницы контакта.
Для наполнения базы данных тестовыми изображениями написан кастомный провайдер FakerImageProvider.
Аутентификация пользователей реализована с помощью стартового набора Laravel Breeze.

## Использование
### Требования
Для запуска проекта достаточно использовать Docker. 
При его отсутствии необходимы PHP v8.1+, MySQL v8.0+, Composer v2, Redis.

### Установка
1. Создайте env-файл в соответсвии с env-example.

2. *При использовании докера*
    - Запустите приложение с помощью следующей команды:
    ```sh
    docker-compose up -d --build
    ```

    - Перейдите внутрь контейнера PHP:
    ```sh
    docker exec -it php81-container-phonebook bash
    ```

    *Без использования докера*
    - Запустите Redis:
    ```sh
    redis-server
    ```

3. Установите необходимые зависимости:
    ```sh
    composer install
    ```

4. Примените миграции и сидеры:
    ```sh
    php artisan migrate
    php artisan db:seed
    ```

5. Создайте символическую ссылку:
    ```sh
    php artisan storage:link
    ```

6. *Без использования докера*

    Запустите локальный сервер Laravel:
    ```sh
    php artisan serve
    ```

7. Откройте в браузере страницу `localhost:{номер-порта-указанный-в-env}` (например, `localhost:8080`).

Можно начинать пользоваться приложением.
